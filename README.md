# PA AI - Personal Assistant AI

PA AI is an intelligent personal assistant that helps users remember important events and manage daily life using human-like interaction.

## Features

- Smart memory-based reminders  
- Voice assistant with natural interaction  
- Context-aware alerts (time, location)  
- Repeats reminders until user responds  
- Emergency safety system with location sharing  

## Example

User:
"I have my wife's birthday on April 10"

PA AI:
- Saves the event automatically  
- Reminds on time using voice  
- Repeats if ignored  
- Encourages the user  

## Emergency Feature

If user says "I am in danger":
- Alerts trusted contacts  
- Shares live location  
- Sends SMS and email  

## Goal

To build a simple and reliable AI assistant that prevents users from forgetting important moments.
